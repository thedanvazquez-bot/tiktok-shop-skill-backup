# Local Training Repos Index

All repos cloned locally for fast reference. Hard rules: NO hashtags, NO em dashes.

## Top 5 High-Signal Files (Read These First)

These are the gold-standard references for TikTok Shop affiliate video scripts.

### 1. `video_gen_prompting.txt` ⭐ MUST READ
Master AI video prompt guide covering Sora 2, Runway Gen 4.5, Kling 2.6, Veo 3.1.
- Universal prompt structure: shot type, camera movement, subject, environment, lighting, duration
- Model-specific techniques and failure fixes
- Strong vs weak prompt comparisons

### 2. `social_video_clipify_architect.txt`
TikTok/Reels/Shorts production specialist. Audio-first discovery, face-pan reframing, caption burning.

### 3. `agentic_video_editor.txt`
Production post-production specialist. ffmpeg + Python + EDL-based editing with hard rules for clean cuts.

### 4. `paid_advertising_architect.txt`
Multi-platform paid ads architect (Google/Meta/YouTube/LinkedIn/TikTok/Microsoft/Apple/Amazon). Platform-specific audit commands and benchmarks.

### 5. `sales_strategist.txt`
Senior sales strategist for deal qualification, pipeline, GTM planning. Useful for affiliate positioning angles.

### 6. `social_card_designer.txt`
Social media image card designer for carousels and covers. Useful for IG carousel cross-posts.

### 7. `market_research_strategist.txt`
Market research director for opportunity sizing, segmentation, competitive analysis.

## Usage Pattern

When scripting a product:
1. Pull `video_gen_prompting.txt` for the AI video prompt structure
2. Reference `prompts.json` in awesome-ad-video-prompts for shot-language examples
3. Apply TikTok-specific filters (7-15s, no hashtags, no em dashes, IG-tailored when asked)
