# CTA Bank

5 CTAs. Pick 4 unique per bundle — no repeats within a single product's 4-prompt set.

1. "Click the link."
2. "Click the link right here."
3. "Price dropped."
4. "See what price you're getting."
5. "Sales don't last long."

If a 5-prompt set is ever requested, all 5 must be unique and the rule relaxes to "no repeat unless all 5 are exhausted." Default 4-prompt bundles never repeat.

Pitfall: rotating too widely across products makes brand voice inconsistent. Default order across consecutive bundles: 1 → 4 → 2 → 5, then shuffle.
