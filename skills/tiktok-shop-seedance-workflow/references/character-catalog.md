# Character Catalog

Default character when a human is needed: **Puerto Rican male, mid-40s, bald, salt-and-pepper beard.** Used unless the product's audience demands a different match.

## When to swap
- The product is gender-specific or audience-specific (e.g. men's skincare, women's activewear) and a default male would undercut the demo.
- The product category has a natural archetype (farming = farmer, gym gear = gym user).
- The user explicitly requests a different demographic.

## Alternates
| Archetype | Best for |
|-----------|----------|
| Athletic blonde woman | Women's fashion, fitness, beauty |
| Father and daughter | Family products, kid products, gifts |
| Farmer | Outdoor tools, rural lifestyle, gardening |
| Gym user | Fitness gear, supplements, athletic wear |
| Outdoor enthusiast | Camping, hiking, emergency gear |

Do not invent character traits beyond what's needed for the script. Don't change race/age/look without a product-driven reason.

## Voice
- Normal speaking speed, natural conversation.
- No robotic speech, no exaggerated influencer energy.
- PG-13 only.
- Spanish phrases acceptable in captions (per the user's bilingual TikTok Shop audience) but the voiceover language matches what the listing reads as — primarily English unless the user asks for Spanish-first.
