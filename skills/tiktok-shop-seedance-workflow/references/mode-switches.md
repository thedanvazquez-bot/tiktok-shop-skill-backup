# Mode Switches

Recipes for triggered sub-modes. Load when the user names a mode in their request. Always keeps the full bundle (4 prompts + SEO + caption) — only the visual/audio style of the 4 prompts changes.

## "Product only"
- No people, no hands, no voiceover.
- Camera work: panning, zooming, push-ins, pull-backs, reveals, macro shots, hero shots.
- Duration: 19-30s typical.
- Audio: ambient only.

## "Luxury" / "Premium" / "High-end"
- Slow cinematic pans and zooms.
- Soft studio lighting.
- Shallow depth of field.
- Commercial-grade camera movement.
- Ambient sounds only (no voice, no music unless asked).

## "ASMR"
- No narration.
- Focus on product sounds: squeeze sounds, soft textures, packaging, slow-motion visuals.
- Category-specific sound cues (e.g. squishy toys: wet squish, soft compression, jelly-like).

## "Panning camera only"
Use this exact beat structure (do NOT vary the timing):
| Beat | Time | Shot |
|------|------|------|
| 1 | 0-5s | Slow reveal |
| 2 | 5-10s | Push in |
| 3 | 10-15s | Orbit |
| 4 | 15-22s | Hero shot |

Tech: 4K UHD, 30fps, smooth gimbal, luxury lighting, clean background, realistic reflections, commercial-grade cinematography. Audio: ambient only, no narration, no music.

## Combination requests
If the user combines modes ("product only luxury", "ASMR panning"), apply ALL the constraints together. When in doubt, surface the conflict and ask which to drop.
