# SEO and Caption Box Formats

## SEO Box
- Single copy box, English + Spanish, no separation, no numbering.
- 50+ keywords/phrases minimum.
- Comma-separated, no bullets.
- Cover: product, use case, audience, category keywords.
- Mix both languages naturally (typically 50/50 or 60/40 EN/ES depending on product).
- Pitfall: stuffing Spanish translations of the English keywords with no localization. Spanish keywords should be what a Spanish-speaking TikTok user actually searches, not direct translations.

## Caption Box — Default (TikTok)
- Single copy box, English + Spanish combined.
- ~400 chars each language (count roughly; strict parity not required).
- Encourage clicks + curiosity.
- Mention 1-2 key benefits.
- CTA at the end.
- Stay compliant (no medical/weight/income claims).
- NEVER hashtags unless explicitly asked.

## Caption Box — Instagram (when asked)
- Triggered when the user says "IG caption", "Instagram caption", "make it IG-friendly", or similar.
- Same English + Spanish combined format.
- First line is a punchy hook.
- Line break every 1-2 sentences.
- Conversational IG-native voice (slightly warmer than TikTok, more story-friendly).
- Clear CTA at the end.
- NEVER hashtags, NEVER em dashes (still applies).

## Caption Box — Both (default + IG)
When the user asks for "captions" plural or doesn't specify, produce the TikTok caption only. Add the IG variant as a clearly labeled second box (e.g. `--- IG CAPTION ---`) so the user can pick.

## Pitfall
- Caption boxes that just translate the SEO keywords into sentences don't convert — they read as filler. Use the listing's actual benefits as raw material.
- Asking the user to confirm length target wastes a turn. Default to ~400 chars and let them push back if they want shorter.
